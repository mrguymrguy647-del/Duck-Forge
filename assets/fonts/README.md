# Fonts

Two fonts for captions and titles, loaded with `Font::load` (see
`docs/AI_GUIDE.md`, "Text in any font"). Both are free to use, change and
share with your games; each one's licence is beside it.

| File | Font | Licence |
|---|---|---|
| `DejaVuSerif-Bold.ttf` | DejaVu Serif Bold (TrueType) | Bitstream Vera licence, DejaVu changes in the public domain: `LICENSE-DejaVu.txt` |
| `Inter-Bold.otf` | Inter Bold (OpenType) | SIL Open Font License 1.1: `LICENSE-Inter.txt` |

They're the unchanged files from the DejaVu and Inter projects
(dejavu-fonts.github.io, github.com/rsms/inter). Any other `.ttf` or `.otf`
file loads the same way.
